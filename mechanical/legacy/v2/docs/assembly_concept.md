# J1～J3 工程粗模装配顺序

所有紧固件、嵌件、配合公差和轴承选型仍为PROVISIONAL。文件用于静态试装和打印结构迭代；不能据此直接释放带载电动样机。

## 制造参数及分件

主体壳壁4 mm；盒体筋4 mm；盖板4 mm；电机固定板6 mm；局部连接平台8 mm。不是把整个底座或连杆做成实心块。J1开口底座外径210 mm，顶面可直接装入电机；有径向筋、两组带嵌件预孔的安装柱和线缆出口。

大臂用24 mm浅弯偏置/90 mm过渡（约14.93°），J2→J3轴线代表点仍为320 mm。实体沿X=180 mm分为两段，接缝两侧各6 mm局部端板，用4个M4通孔连接，中央14 mm过线孔；大臂盖板单独拆卸。未改变关节运动学来凑折线外形。

13个J1～J3打印候选件的STL已导出，均为单一有效实体且重读为封闭网格；尺寸清单在 `analysis/stage2/deliverable_checks.json`。这些是在零件局部坐标下导出的STL，负坐标正常，切片时需放到平台上。

最长的两段大臂已拆开；包围盒可用于核对机型工作范围，但包围盒容纳不证明最优打印方向、支撑、翘曲或强度。220 mm级设备还需给裙边/支撑留余量。金属轴、轴承和输出转接件不列入打印清单。

## J1

1. 先处理底座锚固孔、M3嵌件预孔与走线窗口；用校准试块核对嵌件，不能把未确认预孔直接当成压入公差。
2. 电机从开口上方放入。先将电机前面9-M3接口固定到可拆电机板：螺钉从板的输出侧向电机旋入，中央Ø44避开Ø43固定止口及输出盘。
3. 将电机连同安装板落到底座4个安装柱，用外圈4-M3固定。端子置于后侧预留方向，线缆通过底座侧窗口；实际插头角度待核对。
4. 装J1支承座，底部止口围住安装板外周，另4-M3从座外圈拧入底座较高安装柱；支承放入带肩的座中。
5. 输出转接件固定在转子，输出hub/skirt与独立支承配合，再装上部平台。平台与hub间为4-M4通孔；下侧留出螺母/工具访问空间。
6. 肩架安装完成前仍可从上方拆出电机和支承。底座四个M5锚固孔用于实验台固定，不代表已验证抗倾覆。

仍需确认：J1轴承类型与真实内外圈、轴向压紧/预紧、输出转接件与hub的最终锁紧。当前相接的金属转接面不应当成已设计完成的抗松脱连接。

## J2

1. 左侧电机板与右侧轴承板均为独立件，下部有安装脚/筋，形成跨肩支承；保留右板未装，避免封闭后无法放入大臂输出件。
2. J2电机从左板后侧（-Y）贴合前固定面，9个M3螺钉从+Y固定。先在台面上装好电机板，便于访问螺钉。
3. 把输出转接件与大臂近端盒接口连接；六个输出孔采用实测模型坐标和M4通孔，后续按实际叠层厚度选择螺钉，进入转子不得超过图示有效深度6 mm。
4. 近端盒预留螺钉通孔及较大工具孔。装入金属贯穿轴，再把右侧轴承压入有肩座；从+Y装轴承板套住对侧轴颈。
5. 固定右板到底座平台，装轴承压盖。右板脚的M4嵌件从安装前的底面装入，平台螺钉从下方拧入；左板脚用通孔紧固。
6. 静态手动转动，检查轴承同轴性、轴向卡紧、输出盘偏摆和线缆。拆卸反向执行，不依赖单侧薄悬臂作为唯一支承。

仍需确认：贯穿轴的键/夹紧/止退、压盖外圈/内圈受力区域、轴承预紧、真实电机允许外载。粗模没有把这些配合当作已完成的机械连接验证。

## J3及大臂

1. 先通过大臂两段的4-M4接缝组装盒壳；中间过线孔保持通畅。盖板暂不装，检查螺母/扳手是否能从开放侧进入。
2. J3定子安装板单独与电机前9-M3孔连接。J3对侧轴承板是**可拆件**，此时保持拆下。
3. 电机从肘壳正面（+Y）放入，后部电子区穿过壳后部Ø64孔；安装板用外圈4-M3固定到肘壳预孔。J3定子从此固定在大臂远端壳体上。
4. 在输出端安装一体式金属小臂输出hub：固定盘、短管段和小臂根部连接块为同一设计件，设有沿轴向贯通的六个M4螺钉访问通道，孔位沿用输出接口。必须复核长螺钉可得性、啮合深度和工具路径；不是已经指定了最终螺钉长度。
5. 安装贯穿轴与小臂根部。小臂侧壁有轴孔、输出螺钉头访问孔，盖板有轴夹紧螺钉访问位置。当前夹紧孔只作为金属加工概念，真实轴槽/锁紧方式需定型。
6. 将轴承装入可拆对侧板，套到输出轴颈，再从+Y用2个M4紧固在yoke端面，最后装M3轴承压盖。先拆此板即可再次访问输出长螺钉和电机，不需要破坏大臂壳体。
7. 核对小臂在y=+70 mm侧向折回的空间，然后装大臂盖板。J3定子不随小臂转动，只有输出hub/轴/根部与小臂一起动。

本版父支架横向仍较宽：大臂主壳中心-62 mm、小臂中心+70 mm，差132 mm；对侧支承在约+110 mm。它实现了侧向嵌套与可拆卸性，但还不是最紧凑宽度。J3局部托臂没有跨越小臂主要折回路径，后续可在真实电机/轴承确定后继续缩短轴向堆叠。

## 释放制造前的边界

可立即用于：查看装配、核对模型和实物、切片/静态打印试装、研究安装工具路径。

必须继续完成：真实电机孔位/止口验证；嵌件与轴承选型；金属件锁紧与加工图；打印方向/材料/层间受力；轴承同轴公差；静力/挠度与热；J2扭矩方案；线束与硬限位。螺纹只用孔与预孔表示，没有承诺最终配合与负载。
