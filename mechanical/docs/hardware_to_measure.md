# 实物待测清单

学校四方连接螺母块统一命名 FourWayNutBlock。用户于2026-09-14提供图片并明确指定M4采购版本，按表格第五行选型：`2-M4×8-H10×22`，长22 mm、截面10×10 mm，两个方向孔距均8 mm、M4、图示L3=5 mm。这些是图片标称值，状态为 `PROVISIONAL / IMAGE SPECIFICATION / MEASURE SCHOOL HARDWARE`，不是实物测量。孔深仍为null。

| 项目 | 记录要求 |
|---|---|
| 长、宽、高 | nut_block_size_x / y / z，mm |
| 螺纹规格 | nut_block_thread_size，分别确认两个方向是否一致 |
| 两对孔距 | nut_block_pair_A_spacing / pair_B_spacing，中心距 |
| 空间关系 | 两对孔轴方向、离边距离、所在高度及是否相交 |
| 螺纹孔深 | nut_block_hole_depth_A / B，区分钻孔深度与有效螺纹深度 |
| 是否贯通 | 每个方向分别记录 |
| 可用螺钉长度 | 结合夹层厚度，防止孔底顶死或两颗螺钉相碰 |
| 到货版本 | 型号、数量、材质、是否存在不同孔距或规格 |

独立目录中的 `FourWayNutBlock_PLACEHOLDER` 使用22×10×10 mm图片标称包络。两对孔示意轴相互垂直，孔深仅作展示，不可据此加工；正面离边位置和内孔是否相通必须实测。当前安装数量为0，作为候选标准件交接。

优先评估的连接为J2叉片到大臂、J3叉片到小臂、J4近端壳体到叉片及内部垂直结构。当前几何中可使用M4防松螺母，按用户说明，此件只用于两块独立板材的90°连接；当前叉片与端面、安装耳与底板等平行夹层用螺钉和防松螺母。整体打印的直角筋不增加五金接口。盒梁内部筋/侧壁为同一打印件，那里没有虚构可拆连接。

还需实测CyberGear的9-M3固定孔、6-M4输出孔、螺纹有效深度、止口、整体外形与连接器方向；实验台厚度和孔位；实际套筒/内六角尺寸。所有电机螺钉长度均TBD。轴承型号、金属材料、轴公差和夹紧传扭能力保留给下一阶段。
