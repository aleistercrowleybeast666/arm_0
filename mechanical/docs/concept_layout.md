# 六轴机械臂 v1 构型

本版是可运行、可调整、可做包络检查的概念粗模。电机尺寸、载荷、支承轴承与线缆未确认，因此“无包络穿透”不能等同于可制造或整机工程定型。

## 尺寸与坐标

| 主参数 | mm | 定义 |
|---|---:|---|
| BaseHeight | 180 | 桌面到 J2 轴线高度 |
| UpperArm | 320 | J2—J3 轴线上同一横向基准点之间距离 |
| Forearm | 290 | J3—J4 基准点中心距 |
| Wrist | 60 | J4—J5 基准点间距 |
| Flange | 35 | J5 到 J6 输出端面/法兰基准点 |
| Tool | 90 | J6 输出端面至 TCP，包含 6 mm 接口板及 84 mm 工具占位 |

坐标：世界 X 向前，Y 横向，Z 向上。J1 绕 +Z；J2、J3 绕各自局部 -Y，正角抬高 +X 连杆；J4 绕小臂 +X；J5 绕 J4 转动后的 -Y；J6 绕输出工具 +X。全部角度按右手定则，以全伸展为零。这里的 HOME/STOW 是本轮新定义候选值，未取得旧仿真的同名姿态。

新增横向假设：大臂主梁中心 UpperLane=-75 mm；小臂及腕轴线所在平面 FoldLane=+70 mm。两根主梁中心相隔 145 mm，宽度各 20 mm，平行折叠时仅主梁侧面之间名义间距 125 mm。这个较宽的首版让位量优先验证可折叠性，尚不是紧凑宽度优化结果。J2/J3 的轴线沿 Y，无唯一轴向“中心”；主骨架统一在 y=+70 取代表点，保证 320/290 是真实三维基准点距离。

全伸展 TCP=(795,70,180) mm。795 是沿 X 的长度和；引入侧向偏置后绕 J1 的实际水平半径为 sqrt(795²+70²)=798.08 mm。回导时必须带上 70 mm 偏置，不能仅回传六段长度。

## 六电机优先布局

所有黄色圆柱暂按 Ø80×50 mm，未经厂家或用户 STEP 验证。下表区间用各自上游 link 的局部坐标表示。

| 电机 | 定子所属刚体 | 位置与安装思路 |
|---|---|---|
| J1 | ground | 底座内竖直，z=25…75；输出盘带动肩座 |
| J2 | yaw | 肩轴后侧 y=-52…-2，电机不随大臂俯仰；输出侧经局部 dog-leg 转到外侧主梁 |
| J3 | upper | 大臂肘端 x=320，y=-52…-2；定子随大臂，绝不随 J3 转角带动的小臂旋转 |
| J4 | fore | 小臂末端轴向后置，距 J4 基准点 x=-60…-10；随小臂整体移动 |
| J5 | roll | 距 J4 x=60，侧面 y=-100…-50；J4 转 180° 将其翻到外侧 |
| J6 | pitch | 相对 J5 x=-15…35；定子在 J5 回绕支架内，前端对准法兰基准，完整保留 90 mm 工具段 |

J5 输出支架从 J6 电机侧边绕到其后端，避免横向轴/支架穿过 J6 圆柱包络。电机转子内部没有建模，轴端短圆柱只是连接接口示意；安装孔、真实输出盘与承载轴承需替换。

## 草图到工程结构

本轮未收到草图图片，仅依据 prompt 的文字解释：长外侧大臂、小臂沿侧边折回、肘部让位。具体实现为肩端 x≈60 的局部 dog-leg，将输出接口转接到 y=-75 的长主梁；肘端固定 J3 电机，动侧仅保留短轴/根部连接，把小臂移至 y=+70；小臂折回时两根梁平行错位，不在中央迎头相撞。

J3 定子固定在大臂，使电机主体不进入小臂绕肘的转动扫掠体，降低肘部动侧体积。但 J3 输出的横向悬伸仍会带来弯矩；后续必须补独立支承轴承、实际输出法兰、安装过渡件并核算挠度，不能让未经验证的电机轴承独自承担整臂外载。

## 姿态与展开次序

| 名称 | J1 / J2 / J3 / J4 / J5 / J6（deg） |
|---|---|
| STOW | 0 / 75 / 175 / 180 / 90 / 0 |
| SAFE_UNFOLD | 0 / 75 / 90 / 180 / 90 / 0 |
| WRIST_NEUTRAL | 0 / 75 / 90 / 180 / 0 / 0 |
| WRIST_TURNED | 0 / 75 / 90 / 0 / 0 / 0 |
| HOME | 0 / 45 / 65 / 0 / -80 / 0 |

关键顺序：保持腕朝外，先开 J3；在展开位置把 J5 回中；再转 J4；最后进入 HOME。反向路径即本版收纳候选路径。不把这些名称当成控制器安全认证或真实硬件限位；采样结果见 `validation_report.md`。

对于更深折叠，本轮比较 J4=0 / J5=-90 的朝内腕和 J4=180 / J5=90 的朝外腕。J3 角度探索到 200°，只是几何扫描，不能由此设置硬件限位；线缆、编码器零点与止挡均未建模。

## 蛋糕场景与人工边界

工作区未找到 ArmDesigner、原仿真或默认场景文件。临时假设蛋糕中心 (500,70,150) mm，半径100，高100；顶面200，TCP在210做向下接近。只验证近/中/远代表点和650 mm半径处的一个向下姿态，不代表整个蛋糕曲面、障碍物、连续任务轨迹或刚度都满足要求。完整蛋糕 CAD 与场地碰撞尚未纳入自碰撞报告。

后续优先：真实电机STEP及孔位 → 额定连续扭矩/热/质量与末端载荷 → J2/J3支承和轴向宽度优化 → 真实轴限位和线缆 → 连续碰撞与完整任务路径 → 再细化孔、壁厚与工艺。小臂侧向嵌套成立的代价是横向体积与悬伸，后续应进一步收窄。
