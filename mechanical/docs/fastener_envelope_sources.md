# 标准紧固件包络依据

仅使用M3/M4/M5。CAD用简化头部、光杆、垫片和螺母，不建真实牙型。螺杆显示直径为公称值减0.2 mm，啮合段用简化芯径；结构通孔仍按Ø3.4/4.5/5.5 mm建模。该简化不改变M3/M4/M5采购规格，实际螺纹与全直径配合需试装复核。螺钉长度尚未采购定型；CAD中的夹层与1 mm电机螺纹占位用于空间审查，不能解读为推荐有效旋入深度。

M3/M4垫片占位外径7/9 mm、厚0.5/0.8 mm，M5底座大垫片外径15 mm、厚1 mm；均为待确认的空间包络。螺母采用理想六角外接轮廓，保守覆盖尖角。

打印件正式连接禁止使用热熔铜螺母、塑料攻丝、自攻螺钉或胶粘主承力。金属加工件允许M3/M4内螺纹。螺母槽在拆盖板或按记录拆开子装配后可取出，不形成永久封闭腔。
