# arm_0 V3 装配顺序

本文件描述当前粗模的可拆装逻辑，不是最终工艺卡。所有电机孔位为 **REFERENCE-DERIVED / HARDWARE VERIFY**；轴承是 **GEOMETRIC PLACEHOLDER**，没有采购定型。螺钉长度、螺纹有效深度、嵌件品牌和金属配合需实物确认。

## J1：底座与回转平台

保留已验证的开口底座、径向筋、电机板、轴承座与金属输出hub，平台改为居中的Ø130圆形板。

1. 先装底座嵌件与锚固件；从开口上方装入J1电机及前9-M3固定板，螺钉从输出侧旋入。
2. 固定电机板，安装带肩支承座与80×100×10占位支承；装金属输出连接和旋转平台。
3. 平台中央孔保留工具访问，随后才安装J2两个固定支撑。拆卸反向执行。

J1支承的真实类型、预紧与金属输出件的最终锁紧沿用未完成项；当前形状接触不等于已释放抗松脱设计。

## J2：大臂双叉包住固定电机

从-Y到+Y的概念顺序：短轴颈外法兰 → 大臂对侧叉片 → 可拆轴承压盖/固定轴承支撑 → 电机定子 → 前安装板 → 短输出hub → 大臂输出叉片。两片属于Rigid_upper，定子及轴承固定结构属于Rigid_yaw。

1. 固定前安装支撑与对侧支撑在居中平台上。电机从安装板背面（-Y）放入，叉片尚未安装时从+Y访问前9-M3螺钉。
2. 对侧20×32×10轴承从-Y放入台阶孔，再装带3-M3孔的压盖；不要先封闭大臂双叉。
3. 从+Y将短输出hub贴合转子，随后放置输出侧叉片；六个M4通道贯穿hub和叉片，可从外侧拧入转子。叠层需核算，进入转子的有效孔深不能超过参考标注6 mm。
4. 对侧叉片从-Y装入；25 mm长、Ø19.8轴颈穿过叉片进入轴承，外侧3 mm法兰用4-M3固定。它只覆盖叉片与轴承所需长度，不横贯整个电机。
5. 两叉在约80 mm处接到中央盒梁端框。由盒梁内部访问4-M4连接孔，连接完成后再装大臂盖板。跨关节宽度的扭矩由双叉刚体传递。
6. 维修时先拆盖板和端框连接，拆一侧叉片/短轴颈，再拆输出及定子螺钉；不需要抽出旧式长贯穿轴。

整体关节横向包络约86 mm；对侧轴颈25 mm、含外法兰总长28 mm。输出面到对侧轴承占位中心为46 mm；电机内部承载中心未知，不能把该值当成最终轴承跨距。

## J3：小臂双叉包住大臂末端关节

定子、前安装支撑、对侧轴承支撑属于Rigid_upper；输出hub、对侧短轴颈及两侧小臂叉片属于Rigid_fore。小臂包住关节不改变定子的父刚体。

1. 先在开放的大臂盒梁上安装J3前支撑和对侧支撑。两件与盒梁末端内部隔框连接；隔框承担连接载荷，盖板不是唯一承力路径。
2. 叉片保持拆下，电机从前支撑背面装入；从+Y拧前9-M3。对侧轴承从-Y装入有肩座，安装压盖。
3. 从+Y装短输出hub与小臂输出叉片，从-Y装另一叉片和短轴颈，分别访问转子6-M4及对侧法兰4-M3。端部叠层与J2相同。
4. 在叉片尚未和中央小臂固定前，装J4近端电机及壳体。叉片在J4外周局部张开，之后向中面收拢，通过M4孔固定到小臂端框。
5. 为避让真实Ø75电机及壳体，J3小臂叉在约112 mm处完全并回50 mm中央盒梁，超过初始50～80 mm建议；该延长只发生在关节附近，主体没有恢复整根侧向错层。
6. 先手动检查负J3方向前折，再装大臂/小臂盖板。拆卸按相反顺序进行，先拆小臂端框与一侧叉片即可释放电机访问空间。

关节局部总宽约86 mm；J4附近的叉形局部最大宽104 mm。当前前折验证到J3=-150°，不可把另一方向的+150°或更大的负角直接用于运行。

## J4：近端电机、扭矩管与两端支承

1. 在小臂叉片开放时，将J4电机放入近端壳体。输出面距J3为82 mm，轴向包络中心为63.75 mm。电机轴与原J4数学轴线共线。
2. 从壳体前方装9-M3定子螺钉，再安装6-M4输出适配器。定子随Rigid_fore，适配器随Rigid_roll。
3. 从前端装两处22.2×32×10轴承占位至带肩座，安装带3-M3孔的可拆压盖。轴承支承中心约为小臂坐标x=109和267 mm，间距158 mm。
4. 穿入Ø22、壁2.5、内径17、长192 mm金属扭矩管，范围x=90…282 mm。近端/远端接头有开缝夹紧及横向M3孔的加工概念；近端插接约10 mm，远端约6 mm，夹持长度及扭矩能力尚未定型。
5. 远端hub通过3-M4孔连接J5紧凑金属定子支架。旋转的适配器、管和末端hub全部属于Rigid_roll；小臂壳与轴承座固定在Rigid_fore。
6. 将腕部线束放入独立角部通道：截面8×5 mm，局部Y=12…20、Z=-22…-17。通道贯穿盒梁端框、筋、远端轴承座和压盖；与扭矩管及接头不共用空间。
7. 最后装小臂盖板。检修时先拆盖板/压盖，松开夹紧，再退出管和支承；不是依赖不可拆的封闭细轴。

线槽是静态空间预留，实际线束截面、弯曲半径、转动寿命、接插件出口和屏蔽接地尚未验证。

## J5/J6：前后排列与一体金属连接件

经用户确认，Flange从35改为86 mm。J5输出面沿自身轴移到Y=0；J6沿pitch的+X方向移到86 mm。在腕部伸直时，J5完整电机包络处于J6后方，两转轴仍垂直。转动J5后，J6会绕其运动，不能要求所有姿态仍保持世界坐标前后关系。

1. 将J5电机从紧凑定子支架背面装入；前9-M3孔在轴承座拆下时可从+Y访问。支架通过3-M4接口接J4远端法兰。
2. 从+Y将短金属输出hub固定到J5转子；先完成六个M4螺钉，再沿Ø14.8轴颈滑入独立轴承座。不能预先安装挡住输出螺钉的轴承座。
3. 轴承座通过PCD54的3-M3孔固定。随后从+Y滑入15×32×9轴承占位，到座内台阶，再装3-M3压盖。轴承位于J5输出侧，支承中心Y=13.5 mm。
4. 将J6_OnePieceConnector的开缝夹紧端套入J5短轴的最后12 mm。该件整合夹紧座、6 mm厚连接腹板、J6前安装环和输出轴承鼻座；没有另一侧大框。横向M3夹紧孔及轴向保留孔是加工概念，实际预紧、止退螺纹和摩擦传扭能力未发布。
5. J6电机连同预装短输出轴从连接件后方装入，Ø14.8支承段能穿过前座；9-M3定子孔在锥形鼻座上有工具/螺钉头访问通道。
6. 从J6前方装15×32×9轴承占位与可拆压盖，再装独立的J6_RemovableToolAdapter；它与短输出轴重叠夹持13 mm。工具接头后装，避免两端大法兰把轴承座夹死、无法装配。
7. 拆卸反向进行：工具接头→J6压盖与轴承→J6电机/短轴；再松开J5连接件夹紧→J5压盖与轴承→可拆轴承座→J5输出与定子螺钉。

Tool仍从J6输出基准起算90 mm。承力支架、连接件、短轴和工具接头均标为metal；轴承及夹紧只是几何占位，单侧悬臂的刚度、疲劳和电机内部轴承载荷需要专项验证。连接件为一体复杂金属粗模，具体机加工/铸造路线尚未释放。

## 试装与制造边界

主盒梁壁/筋4.5 mm，J4保护壳4.5 mm；安装板6 mm，叉片局部8～10 mm，紧凑腕部的金属支架/连接腹板为6 mm。螺纹用通孔/预孔表示，承力轴、hub和扭矩管均为metal。

先做接口/嵌件/轴承试块，再打印结构试装。必须继续确认：真实电机接口、轴承类型/预紧、金属夹紧及止退、紧固件BOM、打印方向与材料、刚度/热和最终载荷。当前尚无整机制造发布或带载安全结论。
