# arm_0 Prototype 0 冻结前装配审查

这是一份首次审图用装配顺序，不能代替加工图和实物试装。当前尺寸链180/320/290/60/86/90 mm，两根主体盒梁中心Y=0；冻结姿态不变。接口编号、螺钉数量、方向、接收端和拆卸前置条件见fastener_schedule.csv；数值验证见assembly_validation.json。所有螺钉采购长度TBD。

## 标准件和接收端

电机固定为9-M3通孔拧入CyberGear金属螺纹，输出为6-M4通孔拧入转子；不得把包络中的1 mm螺纹占用当作最终有效啮合长度。打印件主要接口使用M4通孔、垫圈和防松螺母，盖板/压盖局部使用M3可更换金属螺母。金属夹紧件可用待核定的机加工螺纹。热熔嵌件、塑料直接攻牙、自攻螺钉、胶粘承力均不作为正式连接。

FourWayNutBlock按用户指定图片第五行2-M4×8-H10×22选为候选，仅用于两块独立板材的90°连接。本轮叉片端面和安装耳等属于平行夹层，使用螺钉加防松螺母；盒梁直角筋为整体打印，不增加虚构的可拆接口。该连接块当前安装数量0，标称22×10×10 mm、两对孔距8 mm、L3=5 mm，孔深和内部交孔待实测。

## 顺序与维修

1. J1：底座开口时放入可更换金属螺母；安装电机板与9-M3定子螺钉，再装支承座和轴承占位。装6-M4金属输出hub后安装回转平台。J2支撑的M4螺钉由平台下侧凹座向上插入、螺母在支撑脚上侧；在回转部装到底座前完成此子装配。底座四个Ø5.5孔采用M5、加大垫圈与防松螺母固定实验台，台厚未知。
2. J2：在双叉未合拢时安装电机、对侧轴承与压盖；安装输出侧6-M4；对侧叉片与短轴颈先用4-M3在台面预装成一组，再沿轴向插入父轴承。维修时保持这4-M3不动，拆端框后将叉片/短轴颈整组拔出，取出后才访问其内侧螺钉头。压盖先于这组零件安装。两片叉在大臂端框处用4-M4通孔与防松螺母连接。盖板最后安装，螺母槽从开放侧装入。
3. J3：前支撑与对侧支撑通过两颗M4跨越大臂内部隔框，盖板不承担唯一固定作用。安装电机、轴承/压盖，再装小臂两片子叉、输出hub与预装好的对侧叉片/短轴颈组；短轴颈4-M3同J2在台面预装，不能在包住父关节后才拧内侧螺钉。在J4近端电机与壳体安装完成后再合拢叉片、固定小臂盒梁。
4. J4：壳体9-M3、输出适配器6-M4先于扭矩管安装。两端轴承与压盖先装至独立座；局部安装耳以M4固定到底板；远端两颗M4在局部平面直接落座，不装垫圈，以免垫圈边缘碰到压盖，局部压应力须在首件审查中核定。此时扭矩管尚未穿入，才能从上方操作安装耳螺钉。穿入OD22/ID17、长192 mm金属管，安装两端夹紧接头和腕部。近端接头M3防松螺母；远端接头下半金属螺纹避免螺母占用角部线槽。有效螺纹、薄壁局部和夹紧传扭仍待工程确认。盖板最后安装。
5. J5：支架固定到J4远端hub，轴承座拆下时完成9-M3定子和6-M4输出螺钉。然后安装可拆轴承座、轴承、压盖，最后套入并夹紧J6一体金属连接件。标准螺钉头使用局部凹座，不能把压盖与连接件预先封闭后再尝试安装输出螺钉。
6. J6：预装电机与短输出轴，再装输出轴承和压盖，最后夹紧独立工具接头。维修从工具端反向拆卸，先松工具接头，再拆压盖/轴承和电机，随后释放J5连接件及其支承。

维修以卸载、拆开的刚体子装配为检查状态；每个接口的额外拆件清单由工具包络检查给出。紧固件、螺母与垫圈参与整机运动包络检查，内六角工具和螺母退出包络只用于静态维修检查。35 mm为工具进入长度预算，不是腕距。螺母更换需先取出对应螺钉和活动垫圈。

## 审图重点

核对全部金属螺纹有效深度、螺钉长度、锁紧螺母完全啮合、螺钉头凹座的剩余壁厚、M3盖板螺母槽的打印质量。局部避空可能降低刚度；实体有效和几何不相交不证明承载合格。打印件只作为静态试装候选，轴承和电机接口均需实物核对。拆装包络不覆盖工具弯头、手掌和实际扭矩扳手外形。检查中的脱开刚体按上述子装配顺序执行，不表示可在整机封闭状态下访问所有螺钉。
